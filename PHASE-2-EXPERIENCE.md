# Phase 2 — Experience simplification

## Outcome

Reg Mitra now leads with three user jobs:

1. **Today** — decide what deserves attention first.
2. **Clients** — find the client that needs review.
3. **Ask Reg Mitra** — turn a question into a safe, ordered next step.

Briefings, Calendar, Regulations, and Settings remain available under **More**. They no longer compete with the primary workflow.

## Interaction map

| Starting point | User action | Complete local outcome |
| --- | --- | --- |
| Today | Expand a ranked item | See why it matters, its trust state, and the relevant actions |
| Today | Mark reviewed | Remove it from the session queue and advance to the next item |
| Today | Prepare review | Open Ask Reg Mitra with the work item already entered |
| Clients | Search or select risk | See a live, risk-ranked subset and a recoverable empty state |
| Client workspace | Ask about client | Open a client-specific preparation request |
| Ask Reg Mitra | Select or write a prompt | Receive a local, structured review path with explicit limitations |
| Global search | Search a page or client | Jump directly to the first matching workspace destination |
| Regulations | Search or select authority | Filter the local change register and its evidence states |
| More | Change appearance | Switch between light and dark mode for the session |

## Product safeguards

- No interface claims that live AI, client systems, or government portals are connected.
- No fake add, configure, approve, import, send, or attach controls remain.
- Actions requiring production infrastructure explain the missing secure service.
- Regulatory claims remain visibly unverified until a source and reviewer exist.
- Session-only actions clearly state that they reset on reload.

## Visual direction

- One restrained green accent and a neutral working surface.
- Clearer type, spacing, shape, depth, and motion tokens.
- Real SVG iconography with no emoji-based product controls.
- Progressive disclosure for secondary tools.
- Responsive primary navigation and a mobile-accessible More menu.
- User-selectable dark appearance.

## Deliberate boundary

This phase improves the local product experience without pretending that regulated operations are connected. Production-grade client creation, external data retrieval, AI generation, portal access, sending, filing, and approval require authenticated services, encrypted secrets, durable storage, audit logs, and authorization policy.
