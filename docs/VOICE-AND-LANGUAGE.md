# Reg Mitra voice and language

Reg Mitra speaks to working Chartered Accountants. The product should feel calm,
precise, and useful under deadline pressure.

## Voice

- Plain English before product terminology.
- State what changed, who is affected, and what the user can do next.
- Put the official source and review status close to every conclusion.
- Use short sentences. Avoid promotional exaggeration.
- Treat uncertainty honestly without sounding alarmist.

## Preferred terms

| Use | Avoid in the interface |
| --- | --- |
| Official source | Source-locked |
| Source match | Retrieval confidence |
| Regulatory library | Corpus |
| Search by meaning and exact terms | Hybrid or semantic retrieval |
| Workspace access | Entitlement |
| Needs review | Unverified state |
| Prepare a draft | Execute an action |
| Check which clients are affected | Client-impact mapping |

Technical terms may appear in operator diagnostics, logs, and engineering
documentation. They should not be the first language a CA sees.

## Core product sentence

Reg Mitra shows what changed, which clients are affected, and what to do next,
with the official source attached.
