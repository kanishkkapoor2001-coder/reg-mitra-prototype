# Regulatory corpus data

`source-registry.json` is the human-reviewed source of truth for authority, document identity,
applicability, status and canonical URL.

`corpus.json` is generated by the ingestion and embedding scripts. Do not hand-edit it. Each
chunk includes a SHA-256 content hash and source lineage. Empty embeddings are valid for official
index pages because those pages are used for lexical discovery and freshness checks, not semantic
substantive evidence.

Summary-only sources are intentionally visible in corpus health. They must never be mislabeled
as full official text.
